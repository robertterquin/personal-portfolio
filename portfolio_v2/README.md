# Robert Terquin Laqui — Portfolio

Personal portfolio website showcasing cross-platform mobile applications, full-stack web projects, technical stack, certifications, and developer contact information.

**Live Website**: [https://robertterquin.vercel.app](https://robertterquin.vercel.app)

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 7](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/)
- **Email Service**: [@emailjs/browser](https://www.emailjs.com/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18 or higher recommended)
- `npm` or `pnpm`

### Installation

```bash
# Clone the repository
git clone https://github.com/robertterquin/personal-portfolio.git

# Navigate to project directory
cd portfolio_v2

# Install dependencies
npm install
```

### Development

```bash
# Start local development server
npm run dev
```

### Production Build

```bash
# Build optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
